รายงานผลการทดลองปรับแต่ง JavaScript

1. ตรวจสอบวันที่เช็คอินและเช็คเอาท์

ได้เพิ่มโค้ด JavaScript เพื่อตรวจสอบว่าวันที่เช็คอินต้องไม่เป็นวันที่ผ่านมาแล้ว และวันที่เช็คเอาท์ต้องมาหลังวันเช็คอิน โดยใช้ Date() ในการเปรียบเทียบค่าเวลา 


const checkin = new Date(document.getElementById('checkin').value);
const checkout = new Date(document.getElementById('checkout').value);
const today = new Date();

if (checkin < today) {
    alert('ห้ามเลือกวันย้อนหลัง');
    return;
}

if (checkout <= checkin) {
    alert('วันออกต้องหลังวันเข้า');
    return;
}

2. ตรวจสอบเบอร์โทรศัพท์

ใช้ Regular Expression เพื่อตรวจสอบว่าเบอร์โทรศัพท์ต้องเป็นตัวเลข 10 หลักเท่านั้น 


const phone = document.getElementById('phone').value;
const phoneRegex = /^[0-9]{10}$/;

if (!phoneRegex.test(phone)) {
    alert('เบอร์โทรต้องเป็นตัวเลข 10 หลัก');
    return;
}

3. แสดงสรุปการจองก่อนยืนยัน

เพิ่มการใช้ confirm() เพื่อให้ผู้ใช้ตรวจสอบข้อมูลก่อนกดยืนยันการจอง 


const summary = `
ชื่อ: ${fullname}
ห้อง: ${roomtype}
จำนวนวัน: ${days} วัน
`;

if (confirm(summary + '\nยืนยันการจอง?')) {
    alert('จองสำเร็จ');
}

4. รีเซ็ตฟอร์มหลังจองสำเร็จ

ใช้คำสั่ง reset() เพื่อคืนค่าฟอร์มกลับสู่ค่าเริ่มต้นหลังจองสำเร็จ 


document.getElementById('bookingForm').reset();

5. การตรวจสอบแบบ Real-time

เพิ่ม EventListener เพื่อตรวจสอบข้อมูลทันทีเมื่อมีการเปลี่ยนค่า เช่น การกำหนดวันเช็คเอาท์ขั้นต่ำ และการจำกัดจำนวนผู้เข้าพักตามประเภทห้อง 


document.getElementById('checkin').addEventListener('change', function() {
    document.getElementById('checkout').min = this.value;
});

สรุปผลการทดลอง

จากการทดลองปรับแต่ง JavaScript ในแต่ละส่วน พบว่าระบบสามารถตรวจสอบความถูกต้องของข้อมูลได้อย่างมีประสิทธิภาพ ลดข้อผิดพลาดจากการกรอกข้อมูล และเพิ่มความสะดวกในการใช้งานผ่านการตรวจสอบแบบ Real-time รวมถึงการแสดงสรุปก่อนยืนยัน ทำให้หน้าเว็บมีความสมบูรณ์ ถูกต้อง และเป็นมิตรต่อผู้ใช้งานมากยิ่งขึ้น
